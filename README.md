# LJT-Minimal-Homepage

Minimal personal academic homepage of **Junteng Liu**, built with the [Academic Pages](https://github.com/academicpages/academicpages.github.io) Jekyll template.

The site is intentionally kept minimal: a single About page with a short biography, education, research interests, a brief publications paragraph, and contact links. All template demo content (sample publications, talks, teaching, portfolio, blog posts, CV, and guide pages) has been removed.
